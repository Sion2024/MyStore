E-commerce platform for beverages (wines, whiskey, beer, soft drinks, water, etc.)
User authentication and registration with session management
Shopping cart (session-based)
Order management (create, view, track orders)
Product catalog with categories, search, and filtering
Admin panel for product/ user/ order management
Bilingual support: English/ Bulgarian with language toggle
Product search in header
Category filtering
Order status tracking (APPROVED, IN_TRANSIT, DELIVERED)
Admin capabilities: manage products, users, orders
Notification integration: welcome emails, order confirmations, shipping notifications
Session-based cart persistence
MVC pattern with controllers, services, and repositories
Entity models: User, Product, Order, OrderItem, Category
DTOs for cart items and notification requests
Service layer for business logic (CartService, OrderService, UserService)
External notification service client
A full-stack e-commerce application demonstrating Spring Boot, MVC, database integration, and internationalization.
